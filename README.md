
## Prerequisites

Node.js (v18 or higher)
npm (v6 or higher), which comes with Node.js
Visual Studio Code
Git

## Used Extensions

npm - provides to see, add dependencies without using command line
nmp run - to run test via script in packages.json file
npm Intellisense - to autocomplete npm modules in import statements

playwright test for VSCode
Cucumber (Gherkin) Full Support
Github Copilot

playwright snippet - provide code snippets for Playwright
playwright test snippet - provide code snippets for Playwright
